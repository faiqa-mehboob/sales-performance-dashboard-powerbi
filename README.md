
# Sales Performance Dashboard

An interactive Power BI dashboard tracking sales performance across regions and products. Includes KPI cards for key metrics and a quarterly trend line chart to visualize how sales changed over time.

## Features
- KPI cards showing key sales metrics at a glance
- Quarterly trend line chart tracking sales over time
- Breakdown of performance by region and product

## Tools Used
- **Power BI** — data modeling, DAX measures, interactive visualizations
